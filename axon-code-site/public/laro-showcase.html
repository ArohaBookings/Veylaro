Laro Max (24B) — no number here yet

Max wants roughly 24 GB of memory and our test machine has 16, so it has never completed a HumanEval run on our hardware. We could publish a projection. We'd rather publish nothing. The bar goes up the day we measure it on a machine that can hold it, not before.

Why some models aren't on this chart

HumanEval is close to saturated, so several labs have stopped reporting it. Claude Opus 5 and Fable 5, GPT-5.6 Sol, Gemini 3.x and Grok 4.5 have no published HumanEval pass@1 we can cite, so they get no bar. Guessing a number and putting a logo next to it is exactly the thing this page exists to not do. Each appears the day its lab publishes.

The last row is deliberate. A 12B model on your laptop does not beat a frontier datacentre model on raw score, and any page telling you otherwise is selling something. What it does is get within a few points, while never sending a byte, never metering you, and never going down.

Why a small model gets this far

It isn't just weights. It's a system that checks itself.

Most local models are a raw brain and nothing else. Laro wraps its weights in machinery that catches mistakes before you ever see them, which is most of the distance between a 12B model's reputation and that 90.9%.

The existence gate

Before Laro calls an API, it checks the API exists in your actual dependencies. Invented functions are the trust-killer in every coding model, so we made it structurally hard.

It runs what it writes

Laro executes the code and the tests before it hands anything back. When it says a fix works, that's an observation, not a prediction.

A guard on your disk

Every write and every shell command passes a hard filter first. System folders, SSH keys and credential stores are blocked outright, even with full-disk access switched on.

It won't claim work it didn't do

If a step didn't run, Laro says the step didn't run. No "should now be fixed" for something it never executed. This is a rule in the model's charter, not a hope.

Scoped to your project

Point Laro at a folder and that folder is its world. It indexes on-device in seconds and locks its edits to that scope.

Gets sharper overnight, optionally

Turn on overnight learning and Laro refines a small personal adapter on your machine while you sleep. It belongs to you, stays local, and we never collect it. Off by default.
